## 三、逐文件详细改动

### 1. `src/core/player/tempPlayList.ts`

**目的**：提供“加入稍后播放并立即切歌”的专用方法，避免“只入队、不切歌”。

**改动前**：
```ts
export const addTempPlayList = (list: LX.Player.TempPlayListItem[]) => {
  playerActions.addTempPlayList(list)
  if (!playerState.playMusicInfo.musicInfo) void playNext()
}
```

**改动后**：
```ts
export const addTempPlayList = (list: LX.Player.TempPlayListItem[]) => {
  playerActions.addTempPlayList(list)
  if (!playerState.playMusicInfo.musicInfo) void playNext()
}

/**
 * 添加歌曲到稍后播放列表并立即播放
 * 与 addTempPlayList 不同:无论当前是否正在播放,都会切到新歌。
 * 会强制插到稍后播放列表顶部,避免被已有队列里的歌曲抢先。
 */
export const addTempPlayListAndPlay = (list: LX.Player.TempPlayListItem[]) => {
  playerActions.addTempPlayList(list.map(({ isTop, ...item }) => ({ ...item, isTop: true })))
  void playNext()
}
```

**关键点**：
- 新方法 `addTempPlayListAndPlay` 会先强制把传入歌曲标记为 `isTop: true`，保证插到稍后播放列表顶部。
- 然后调用 `playNext()`，这样无论当前是否有歌曲在播，都会播放刚插入的这首。
- 原 `addTempPlayList` 保持不变，不影响其他“加入稍后播放但不立即切歌”的业务。

```ts
const handlePlaySong = useCallback(async (song: LX.Stats.SongItem) => {
  // 优先从原始事件里找回完整 musicInfo(含 source 等播放必需字段)
  let musicInfo: LX.Music.MusicInfo | null = null
  try {
    const events = await getStatsEvents()
    for (let i = events.length - 1; i >= 0; i--) {
      if (events[i].musicInfo?.id === song.id) {
        musicInfo = events[i].musicInfo
        break
      }
    }
  } catch {}
  if (!musicInfo) {
    // 事件已被清理(90 天前)时,退化为最小 musicInfo
    musicInfo = {
      id: song.id,
      name: song.name,
      singer: song.singer,
      source: 'kw' as LX.OnlineSource,
    } as LX.Music.MusicInfo
  }
  addTempPlayListAndPlay([{ listId: null, musicInfo }])
}, [])
```
