# LX Music Pro — 颜值线(UI/视觉方向参考)

> 建立:2026-08-18 · 琥珀提出"想要 Salt Player 优秀的地方",墨白调研后落档
> 定位:给 UI/前端开发者的**视觉方向参考**,不是硬性规范——开发者可发挥,但遵循这里的"设计语言"

## 〇、一句话

**让界面"摸得到质感、看得见温度"** —— 不是堆特效,是每个界面都让人觉得"这个 App 有审美"。

## 一、主要参考对象:Salt Player(椒盐音乐)

> **注意**:Salt Player 应用本体**闭源**(不可直接抄代码),但官方开源了 **SaltUI**(UI 组件库,Apache-2.0)和 **media-kit**(媒体服务,LGPL-2.1)——**设计语言可以借鉴,代码是同栈(Kotlin/Compose)但我们是 RN 不能直接搬,借鉴思路**。

**Salt Player 值得学的点(颜值维度):**

| 特色 | 说明 | 对我们(React Native)的启示 |
|---|---|---|
| **毛玻璃/背景模糊** | 播放页封面模糊做背景 | RN 可用 `@react-native-community/blur` 实现 |
| **动态取色(Material You)** | 界面颜色跟随当前歌曲封面 | RN 可用 `react-native-image-colors`(策划⑤已计划引) |
| **流体动效** | 转场/卡片过渡顺滑,不僵硬 | Animated + 恰当的时长(300ms 上下),不做生硬跳变 |
| **沉浸式歌词** | 歌词页遮住一切,专注文字 | 歌词展示模块(实用线)可借鉴 |
| **简洁克制** | 信息层级清晰,不拥挤 | 每个页面的元素"少而精" |
| **系统适配** | 状态栏/导航栏/小组件融为一体 | 后期做小组件时参考 |

**开源可直读的:**
- UI 设计语言示例:SaltUI 仓库 `github.com/Moriafly/SaltUI`(看它的 screenshot/文档,提炼视觉)
- 媒体/通知适配思路:Salt media-kit `github.com/Moriafly/media-kit`

## 三、颜值线候选池(方向性,开发者发挥)

- **主题系统扩展**:自定义色/壁纸模糊/深浅档——让 App 有"表情"
- **播放页视觉**:封面动效/渐变背景/歌词随动(参考 Salt 的沉浸感)
- **列表与动效**:进入动画/过渡顺滑,不机械
- **统计可视化**:热力图/条形已有,可加环形/雷达等更丰富的图表

## 四、颜值线设计原则(给开发者的三条)

1. **宁简勿繁**:一个页面一个焦点,元素少而精
2. **动效有原因**:过渡动画是"引导注意",不是为了炫技;时长 200-400ms,快了生硬慢了拖沓
3. **颜色听歌的**:能用歌曲封面取色就别用固定色板(音乐 App 的天然优势)
