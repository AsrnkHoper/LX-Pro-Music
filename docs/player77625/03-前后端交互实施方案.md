## 二、查数据层（查询 API）

### 2.1 页面级共享加载（解决重复全表加载）

**现状问题**：原版 `index.tsx` 每次刷新并发调 `getStatsOverview + getStatsTopSongs + getStatsTopArtists`，其中 `getStatsSong()` 被调两次。MonthHeatMap/YearOverview 各自又调 `getStatsDailyByRange`。

**方案**：页面级一次并发加载三张表 + play_history，传入内存给各 section，子 section 不再各自调查询 API。

```typescript
// index.tsx
interface StatsPageData {
  daily: LX.Stats.DailyItem[]
  song: LX.Stats.SongItem[]
  events: LX.Stats.EventItem[]
  history: LX.Player.PlayHistoryItem[]
}

const [pageData, setPageData] = useState<StatsPageData | null>(null)
const [loading, setLoading] = useState(true)

const loadAll = useCallback(async () => {
  const [daily, song, events, history] = await Promise.all([
    getStatsDaily(),
    getStatsSong(),
    getStatsEvents(),
    getPlayHistory(),
  ])
  setPageData({ daily, song, events, history })
  setLoading(false)
}, [])

useEffect(() => {
  loadAll()
  const handleUpdate = () => loadAll()
  global.app_event.on('statsUpdated', handleUpdate)
  global.app_event.on('playHistoryUpdated', handleUpdate)
  return () => {
    global.app_event.off('statsUpdated', handleUpdate)
    global.app_event.off('playHistoryUpdated', handleUpdate)
  }
}, [loadAll])
```

### 2.2 各 section 从 props 接收已加载数据

```typescript
// 每个 section 的 Props
interface SectionProps {
  data: StatsPageData       // 已加载的全量数据
  range: TimeRange          // 当前时间范围
}
```

### 2.3 例外：交互式查询（仍走原 API）

以下场景数据量大或依赖用户交互，不走共享加载，仍用原 API：

| 场景 | API | 原因 |
|---|---|---|
| 热力图切换月份 | `getStatsDailyByRange(monthStart, monthEnd)` | 按月范围过滤，避免全量 daily 传给子组件 |
| 点击日期看账本 | `getStatsEventsByDay(date)` | 按天过滤 events |
| 删除当天 | `deleteStatsDay(date)` → 触发 `statsUpdated` → 页面重载 |
| AI 报告生成 | `generateWeeklyReport(force)` | 异步长耗时，独立流程 |
| AI 报告缓存 | `readCachedReport()` | 独立读取 |
| AI 报告档案 | `getReportArchive()` | 独立列表 |
| 导出/导入 | `exportStatsData()` / `importStatsData(data)` | 文件 IO |

### 3.2 纯函数清单

所有函数接收已加载的内存数据 + 时间范围，返回结构化结果。**无 IO、无副作用**。

```typescript

function getPrevRangeStart(range: TimeRange): number  // 上期起点（趋势对比用）
function getPrevRangeEnd(range: TimeRange): number

// ===== 概览派生 =====
function calcStreak(daily: DailyItem[]): { current: number; max: number }
// 从 daily 按日期排序，算当前连续 active 天数 + 历史最长

function calcDailyAvg(daily: DailyItem[], range: TimeRange): number
// 周期内日均时长（秒）

function calcTrendCompare(
  daily: DailyItem[],
  range: TimeRange

// 本期 vs 上期每日时长序列 + 变化百分比

// ===== 雷达 6 维 =====
function calcRadarProfile(
  song: SongItem[],

  daily: DailyItem[],
  range: TimeRange

  diversity: number      // 0~1 香农多样性 / log(N)

  completion: number     // 0~1 playTime/maxTime ≥ 0.9 占比
  activity: number       // 0~1 活跃天数 / 周期天数
  discovery: number      // 0~1 周期首播歌曲数 / 总歌曲数

function calcPyramidTiers(
```

### 3.3 时间范围过滤

所有函数内部先按 `range` 过滤数据：

```typescript
function filterByRange<T extends { playedAt: number }>(
  items: T[],
  range: TimeRange
): T[] {
  const start = getRangeStart(range)
  const end = getRangeEnd(range)
  return items.filter(item => item.playedAt >= start && item.playedAt <= end)
}

function filterDailyByRange(
  daily: DailyItem[],
  range: TimeRange
): DailyItem[] {
  const start = getRangeStart(range)
  const end = getRangeEnd(range)
  return daily.filter(item => {
    const time = new Date(`${item.date}T00:00:00`).getTime()
    return time >= start && time <= end
  })
}
```

## 五、AI 报告交互流程

### 5.1 入口（统计页内）

```
用户点击"生成报告"按钮
  → reportRef.current?.generate()
  → ReportView 打开全屏 Modal
  → handleGenerate(force=true)
  → setGenerating(true), 三态进度展示
  → generateWeeklyReport(force=true)
    → buildPeriodFacts(start, end)        // 本地算事实层
    → buildAiSystemForReport()           // 系统提示
    → chatCompletion({...})              // 请求 AI
    → parseReportV2 + validateReportV2   // 解析+校验
    → 失败重试一次
    → finalizeReport(raw, facts, period)  // 本地补算
    → saveReportCache + addReportToArchive
  → setReport(res.report)
  → setGenerating(false)
  → StoryFlow 渲染报告
```

### 5.2 档案馆

```
用户点击"报告档案"
  → reportRef.current?.openArchive()
  → getReportArchive() → setArchive(list)
  → 展示历史报告列表
  → 点击某条 → setReport(item.report) → 切回 StoryFlow 展示
  → 删除 → deleteReportFromArchive(id) → refreshArchive()
  → 导出 → ChoosePath → handleSaveFile
  → 导入 → ChoosePath → handleReadFile → importReportArchive(data)
```

## 六、排行播放交互流程

### 6.1 修复方案（解决 `source:'kw'` 硬编码）

```typescript
// 在 RankingsSection 内
const handlePlaySong = useCallback((songId: string) => {
  // 1. 优先从内存歌单反查完整 musicInfo
  const allLists = [
    ...listState.defaultList,
    ...listState.loveList,
    ...listState.userList.flatMap(u => u.list ?? []),
  ]
  const fullInfo = allLists.find(m => m.id === songId)

  if (fullInfo) {
    addTempPlayList([{ listId: null, musicInfo: fullInfo }])
    play()
    return
  }

  // 2. 回退：从 play_history 反查
  void getPlayHistory().then(history => {
    const histItem = history.find(h => h.musicInfo.id === songId)
    if (histItem) {
      addTempPlayList([{ listId: null, musicInfo: histItem.musicInfo }])
      play()
    } else {
      toast('无法播放：缺少歌曲来源信息')
    }
  })
}, [listState])
```

| 风险 | 影响 | 缓解 |
|---|---|---|
