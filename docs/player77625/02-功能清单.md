## 各模块详细规格

### 1. 概览数字

**数据**：`getStatsOverview()` → `{totalPlays, totalDuration, activeDays}`

**展示**：
- 3 个大数字：播放次数 / 累计时长（格式化为 Xh Xm）/ 活跃天数
- 4 个子指标：连续天数（🔥）/ 历史最长连续 / 日均时长 / 较上期 delta%
- 数字带发光效果

**派生计算（`aggregate.ts`）**：
- `calcStreak(daily)` → `{current, max}`：从 daily.active 数组算当前连续 + 历史最长
- `calcTrendCompare(daily, period)` → `{current, previous, deltaPct}`：本期 vs 上期

---

### 2. 听歌画像雷达

**数据**：从 song/events 派生 6 个维度，各归一化到 0~1

**6 轴定义**：
| 轴 | 含义 | 计算方式 |
|---|---|---|
| 多样性 | 听歌广度 | 香农多样性指数 / log(总歌曲数) |
| 深夜 | 深夜占比 | 23:00-05:00 播放时长 / 总时长 |
| 循环 | 循环痴迷度 | Top1 歌曲次数 / 总次数 |
| 完听 | 完整收听率 | playTime/maxTime ≥ 0.9 的事件占比 |
| 活跃 | 活跃度 | 活跃天数 / 周期天数 |
| 探索 | 新发现度 | 周期内首次播放的歌曲数 / 总歌曲数 |

**展示**：SVG `Polygon` 4 层网格 + 6 根辐条 + 数据区渐变填充 + 描边 + 数据点发光（`feGaussianBlur`）

**动画**：数据区从中心 `scale(0→1)` 弹性展开，数据点逐个亮起

---

### 3. 歌曲金字塔

**数据**：`aggregate.calcPyramidTiers(song, range)` → 4 层

**分层规则**：
| 层 | 名称 | 条件 | 颜色 |
|---|---|---|---|
| 1 | 循环之王 | plays ≥ 10 | 最亮（accent 高不透明度） |
| 2 | 常听 | plays 5~9 | 中亮 |
| 3 | 偶听 | plays 2~4 | 暗淡 |
| 4 | 试听 | plays 1 | 最暗 |

**展示**：SVG 梯形 `Path` 堆叠，每层渐变填充 + 标签 + 歌曲数/次数

**动画**：从顶到底逐层下滑淡入

---

### 4. 听歌日历（月/年内嵌切换）

**数据**：
- 月度：`getStatsDailyByRange(monthStart, monthEnd)` + `getStatsEventsByDay(selectedDate)`
- 年度：`getStatsDailyByRange(yearStart, yearEnd)`

**月度视图**：
- 6×7 日历网格（周一开头，42 格，邻月补齐半透明）
- 格子颜色 = `getHeatColor(duration, maxMonthDuration)`（HSL 绿→黄→橙→红连续渐变，当月最大日=深红）
- 点击格子 → 选中（高亮边框）→ 下方展开当天账本明细（歌曲名/歌手/时间，可点击播放）
- 长按格子 → 确认弹窗 → `deleteStatsDay(date)` 删除当天数据
- 月份切换：‹ › « »（年/月步进）

**年度视图**：
- GitHub 风格 53 列 × 7 行 = 371 格
- 每格一天，颜色 = `getHeatColor(duration, maxYearDuration)`
- 横向滚动
- 满色基准 = 全年听歌最多的那天

**切换**：面板内 segmented toggle（月度 | 年度），无页面跳转

---

### 5. 时间分布

**数据**：`aggregate.calcHourlyDist(events, range)` → `number[24]`；`aggregate.calcWeekdayDist(daily, range)` → `number[7]`

**展示**：
- 24 小时柱状图：24 根渐变柱（底部暗→顶部亮），峰值柱发光
- 星期柱状图：7 根（周一~周日），最高柱发光

**动画**：每根柱从底部 `scaleY(0→1)` 生长，错峰

---

### 6. 趋势对比

**数据**：`aggregate.calcTrendCompare(daily, period)` → 本期 vs 上期每日时长序列

**展示**：
- 双线折线图：本期（实线 + 发光）+ 上期（虚线 + 半透明）
- 渐变面积填充（本期）
- 数据点发光
- X 轴 = 日期标签

**动画**：路径 `stroke-dashoffset` 自描画 → 面积淡入 → 数据点逐个亮起

---

### 7. 有效收听率

**数据**：`aggregate.calcEffectiveRatio(events, range)` → `{effective, ineffective}`

**展示**：环形图（`stroke-dasharray` + 渐变描边 + 发光）+ 中心百分比数字 + 图例

**动画**：`stroke-dashoffset` 从满到目标扫描 + 中心数字延迟亮起

---

### 8. 来源分布

**数据**：`getPlayHistoryByRange(start, end)` → 按 `source` 字段聚合（Search/Rec/Detail/List）

**展示**：环形图（三色渐变描边）+ 中心最大占比 + 图例

**动画**：同上

---

### 9. 歌曲排行

**数据**：`getStatsTopSongs(limit=10)`

**展示**：列表行（排名 + 封面占位 + 歌名 + 歌手 + 次数 + 进度条）

**交互**：点击 → 从 `allMusicList` 反查完整 musicInfo → `addTempPlayList` + `play()`

**动画**：进度条 `width 0→target` 延迟生长

### 10. 歌手排行

**展示**：同歌曲排行，副标题显示"次数 · 首数"

### 11. AI 听歌报告

**入口面板**（统计页内）：

- 三态：generating（ActivityIndicator + 三阶段文案"正在读你的数据…/正在写你的一周…/正在装信…" + 进度条 + 已等待秒数）/ archive（历史报告列表）/ report（StoryFlow）

  - 横向 `FlatList` pagingEnabled + 底部圆点

## 拓展性机制

### Section 注册表

`index.tsx` 内维护一个 section 数组，每个 section 是一个自包含组件：

```typescript
const SECTIONS = [
  { id: 'overview',  component: OverviewSection,  defaultOn: true },
  { id: 'radar',     component: RadarSection,     defaultOn: true },
  { id: 'pyramid',   component: PyramidSection,   defaultOn: true },
  { id: 'heatmap',   component: HeatmapSection,   defaultOn: true },
  // ... 加一个 section = 加一行 + 写组件
]
```

新增展示模块只需：写一个 section 组件 + 注册一行。无需改架构。

### 用户自定义（页内控件，不落设置）

- 时间范围 SegmentedControl：周/月/年/全部（联动大部分 section）
- 每个 section：可折叠、TopN 步进器、图表类型切换
- 预设色板切换（页内浮动，不持久化到设置）
