# 更新记录

## v26.07.23 — 本地歌词多格式导入

### 新增功能

支持从音频同目录自动读取外部歌词文件，覆盖以下格式：

| 扩展名 | 格式 | 说明 |
|---|---|---|
| `.lrc` | 标准 LRC | 时间标签归一化（毫秒补 3 位）后直通 |
| `.esl` | ESLyric（增强 LRC） | 含 Kugou 式 `<ms,dur>` 逐字标签时产出 `lxlyric` + `lyric`；否则按标准 LRC 处理 |
| `.srt` | SubRip 字幕 | 起始时间转 `[mm:ss.ms]`，多行文本合并 |
| `.vtt` | WebVTT | 剥离 `WEBVTT` 头与 `<c>`/`{}` 内联标记后转换 |

### 行为约定

- **自动探测**：播放音频时，依次在同目录查找同名 `*.lrc` → `*.esl` → `*.srt` → `*.vtt`，命中首个即用，无需手动操作。
- **优先级**：外部同名文件 > 音频内嵌元数据歌词。外部文件解析失败或无歌词时回退内嵌。
- **逐字歌词**：`lxlyric` 沿用现有 KRC/YRC/MRC 的处理方式，仅用于下载/导出，不接入应用内逐字显示。
- **缓存**：与内嵌歌词共用既有缓存链路；编辑磁盘同名文件不会触发缓存刷新。

### 已知限制

- 仅支持 UTF-8（自动剥离 BOM）；GBK 编码文件暂不支持。
- `.esl` 仅处理 Kugou 式 `<ms,dur>` 逐字标签；Enhanced LRC 行内词级标签暂按普通 LRC 直通。
- WebDAV 音乐仅查找本地下载目录中的同名文件，不回退远端。
